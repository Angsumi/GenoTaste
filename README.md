# GenoTaste - Genomic Wellness Landing Page

> **NATURE • NURTURE • KNOWLEDGE**

A sleek, premium, modern landing page for **GenoTaste**, a genomic wellness consulting brand. GenoTaste helps clients understand their genetic wellness reports and translate relevant insights into practical nutrition, lifestyle, fitness, and recovery decisions.

## Features
- **Sleek Aesthetic**: Sophisticated warm gold/amber, light natural green, deep charcoal/navy palette with subtle glassmorphism and rounded cards.
- **Hero & Centerpiece**: Uses the official GenoTaste logo as a visual centerpiece.
- **Interactive Question Filter & Detail Drawer**: Real client questions categorized with biological context.
- **Before vs. After Comparison**: Clear contrast between unprioritized 80-page PDFs and GenoTaste's human interpretation.
- **5-Step Process**: Discover → Interpret → Prioritize → Personalize → Act.
- **Consultation Packages & Interactive Quiz**: Match quiz modal to guide client package selection.
- **Booking Intake Workflow**: Multi-step booking intake modal.
- **Ethical Boundaries & FAQ Accordion**: Clear non-medical disclaimer and transparent privacy practices.

## Technologies Used
- HTML5 / Vanilla JavaScript
- Modern CSS (Custom Properties, Glassmorphism, Responsive Flex & Grid)
- Google Fonts (`Outfit` & `Plus Jakarta Sans`)
